# Last Minute Life Saver

An AI-powered productivity assistant that transforms unorganized tasks into structured, actionable plans using Google Gemini API.

## Overview

Last Minute Life Saver is an intelligent productivity system designed to help users manage time effectively. Instead of acting as a simple reminder tool, it actively analyzes tasks, prioritizes them based on urgency, and generates a clear execution plan.

The goal is to reduce procrastination and improve decision-making through AI-driven guidance.


## Problem

Most users struggle with:
- Missed deadlines due to poor planning
- Lack of task prioritization
- Overwhelming to-do lists
- Inefficient time utilization

Existing tools notify users but do not help them decide what to do next.


## Solution

This project introduces an AI-assisted task management system that:
- Collects user tasks and deadlines
- Uses AI to analyze urgency and importance
- Converts tasks into a structured daily action plan
- Helps users focus on high-impact work first


## Key Features

- Task input with deadline tracking  
- AI-based priority analysis  
- Structured daily planning output  
- Urgency highlighting system  
- Action-first productivity approach  
- Real-time AI processing using Gemini  


## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- Google Gemini API (Google AI Studio)


## AI Engine

Powered by Google Gemini API, the system:
- Understands natural task inputs
- Evaluates urgency based on deadlines
- Generates structured productivity plans
- Provides actionable next steps


## Workflow

User Input → AI Processing → Priority Analysis → Structured Plan → Output Display
